# Project 1: Data Cleaning & Preparation

## 📌 Goal
Clean a raw e-commerce dataset (16,000+ orders) by handling missing values, removing duplicates, and correcting data formats.

## 🛠️ Tools Used
- Python (Pandas)
- Google Colab

## ✅ Steps Performed
1. Filled missing values in CouponCode with "None"
2. Removed duplicate rows
3. Corrected Date and Number formats
4. Created CheckTotal column for verification
5. Exported cleaned dataset
